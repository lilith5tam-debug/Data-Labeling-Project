## 🇸🇦 Project 1: Advanced Arabic NLP & Sentiment Annotation (High Difficulty)
This project showcases the ability to handle complex Arabic linguistic nuances, Named Entity Recognition (NER), local idioms, and context-dependent tone analysis for Large Language Models (LLMs).

### 🔍 Demo Annotation Sample:
* 🗣️ **Source Text:** *"يا جماعة، أنا طلبت تذكرة لرحلة دبي من مكتب الطيران في الرياض بتاريخ 15 مايو، وللحين ما وصلني التأكيد! هل هذا يعقل؟ الدعم الفني نايم في العسل."*
* 📌 **NER Tagging:** Extracts locations (*دبي, الرياض*), dates (*15 مايو*), and organizations (*مكتب الطيران*).
* 🎭 **Tone Detection:** Captures complex sarcasm and frustration (*نايم في العسل*).

*📂 Output File:* `arabic_nlp_labels.json` (Structured in standard JSON format)
