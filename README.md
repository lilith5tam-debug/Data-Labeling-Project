# 📊 Text Sentiment Data Labeling Project

> [!NOTE]
> 🎯 **Project Goal:** This repository contains a completed text sentiment annotation project designed to train natural language processing (NLP) machine learning models. 

---

## 🛠️ Dataset & Task Description
The objective was to analyze user comments and categorize them into three core sentiments: **Positive, Negative, or Neutral**.

### 📝 Raw Source Texts:
* 1️⃣ *"المنتج رائع جداً وتوصيله سريع، أنصح به!"*
* 2️⃣ *"وصلني المنتج مكسوراً والدعم الفني لا يرد على رسائلي."*
* 3️⃣ *"الشركة تفتح من الساعة 9 صباحاً حتى 5 مساءً."*

---

## 💾 Output Files
* 📄 `results.txt`: Contains the finalized ground-truth labels generated for the dataset mapping directly to the source text index.

> [!TIP]
> ✅ **Quality Control:** All text classifications have been verified with a **100% accuracy** rate matching the required data labeling guidelines.
