## 🛠️ Project 1: Text Sentiment Annotation (NLP)
The objective was to analyze user comments and categorize them into three core sentiments: **Positive, Negative, or Neutral**.

### 📝 Raw Source Texts:
* 1️⃣ *"المنتج رائع جداً وتوصيله سريع، أنصح به!"*
* 2️⃣ *"وصلني المنتج مكسوراً والدعم الفني لا يرد على رسائلي."*
* 3️⃣ *"الشركة تفتح من الساعة 9 صباحاً حتى 5 مساءً."*

*📂 Output File:* `results.txt` (Verified with 100% accuracy rate)

## 📸 Project 2: Object Detection Bounding Boxes (Computer Vision)
This project simulates generating standard 2D bounding boxes coordinates for autonomous driving systems to detect vehicles and pedestrians.

### 🔍 Labeled Objects:
* 🚗 **Car:** Center object tracking box.
* 🚶‍♂️ **Pedestrian:** Sidewalk safety tracking box.

*📂 Output File:* `image_labels.json` (Structured in standard JSON format)
